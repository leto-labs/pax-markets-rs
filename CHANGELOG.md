# Changelog

## 0.0.1

- Public metadata and TLS/WebSocket client with bounded delivery and recovery.
- Exact integer decoding, deterministic book reconstruction, and liquidity queries.
- Capture/replay, optional sampled latency diagnostics, and a responsive HTML demo.
- Offline fixtures, differential reconstruction tests, and reproducible benchmarks.
- Optional namespaced AWS deployment with CloudFront HTTPS and release rollback.
